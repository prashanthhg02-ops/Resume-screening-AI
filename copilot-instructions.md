# Shortlist workspace

- This is a local Flask resume screening app.
- Keep screening explainable: TF-IDF similarity plus explicit skills from `SKILL_VOCABULARY` in `app.py`.
- Do not add external API requirements or send resume content to third-party services.
- Run locally with `py app.py` after installing `requirements.txt`.
- Keep the frontend responsive and preserve the existing navy, warm white, teal, and yellow visual language.
